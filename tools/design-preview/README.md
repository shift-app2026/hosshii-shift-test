# ローカルのデザイン確認専用ビルド

既存アプリの認証・無料体験・保存処理は変更せず、リポジトリ外の空フォルダーに安全なプレビューを生成します。デプロイ機能はありません。

```sh
python tools/design-preview/build.py --output /workspace/pr8-local-preview
```

フォントは作成時に取得・同梱します。既に同梱したフォントを再利用する場合は `--font-cache /path/to/preview/fonts` を指定できます。

起動時のLINE SDK・認証/無料体験判定・Supabase通信コードを除外し、保存参照を架空データのメモリ内Mapに切り替えます。バックアップやファイル入出力、外部リンクは停止します。CSPも同梱し、外部サービスへの通信を禁止します。

元アプリと同じCSSを使用します。ポップアップ先頭の余白も、元アプリの非表示要素の有無に依存しない共通CSSで統一しています。認証を迂回するフラグを元アプリへ追加する方式ではありません。

Cloudflare再デプロイ、mainへのマージ、本番公開は別途ユーザーの許可が必要です。このビルドはそれらを実行しません。
