# PR #8：Android実機確認後の読みやすさ・配置調整

修正前：`918563b`。PR #8の `design/bordeaux-rose-champagne` のみを変更。Zen Maru Gothic、ワインレッド／シャンパンゴールド、光沢ボタン、勤務先色・土日祝色は維持しています。

## 文字の濃さを役割別に調整

公式の500・700を使用。公式600がないため擬似600や文字色の変更で調整せず、基準の無料お試し見出し・勤務先名と同じ700を、読み取りや操作に必要な箇所へ選択的に適用しました。

- **700に強化**：給与内訳の項目・期間・勤務時間・金額、目標金額（円グラフ外）、受取済み給与、年収の壁、カレンダーの日付・曜日、予定表の時間・日付・お給料日、数値入力、短い注意書き、コピー／登録案内、操作に関するポップアップ説明、はじめにの導入・手順。
- **500を維持**：長い利用案内・規約等の段落。文字を17pxにし、行間と語のまとまりで読みやすく調整。500を一律に700へ変更していません。
- **既存の700を維持**：無料お試しの見出し、勤務先名、各見出し、下部タブ、登録・保存・削除等のボタン。

書体そのものと公式フォントファイルは変更なし。新しい色・背景・塗り・線の色の宣言は追加していません。登録／保存／実行の金文字・白文字の切り替えも維持しています。

円グラフ下は16pxのまま、両幅とも指定の3行です。

> 　併せて計算してお給料見込額の合計を

コピー案内は両画面で次の2行に統一。📋と文章は全角1文字分（16／17px）、文章と実行ボタンも間隔を確保して縦中央揃えです。

> ※前月のシフトを曜日に  
> 　合わせて　一括コピー

カレンダーの登録案内も大きくし、右側の「＋シフト登録」を縦中央に維持しました。予定表の操作説明は文章を変えず、意味のまとまりで折り返し、語尾だけが残らないようにしています。

## カレンダーの♡と、案内文の改行

- カレンダーの数字を前面（z-index 2）、♡を背面（1）にしました。位置・輪郭SVG・色・1日1個の仕様は維持し、数字を優先して読める重なりです。
- 「見てね♡」はひとまとまりで表示。
- ホーム画面追加・データ保存／バックアップの見出しは両幅とも1行。320pxのみ必要な横余白と14pxの見出しを使用し、375pxは16pxを維持。
- プライバシーポリシーの長い見出しは意味の切れ目で2行にし、語の途中で切らないようにしました。
- 利用案内の文言は変えず、「確認できます。」「記載しています。」「保存してね♡」等の終わりや、引用した利用規約の名称をひとまとまりにして、孤立する「す。」「きます。」「す♡」等を防止。
