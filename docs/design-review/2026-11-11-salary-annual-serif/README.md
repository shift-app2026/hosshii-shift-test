# 年間収入カード：Noto Serif JPへの統一

変更前：`45ab3eb`。変更後のアプリコード：`15e2d69`。今回のアプリ変更はお給料画面のCSSのみです。

## 変更内容

- 「確認する金額」、選択欄の「130万円（参考）」「103万円（参考）」、下部の説明文をNoto Serif JPに統一しました。
- 「見てね♡」、年間収入の補足も含めてカード内の全要素を同じ書体としました。「130万円までの残り」、赤い金額表示、カード見出しも同じ書体であることを確認しています。
- 選択欄と、旧CSSの#333が残っていた説明文を#302027に統一。赤い金額・ボタンの強調色は維持しています。
- 文字サイズ・太さ・字間・行間・余白・背景・枠線を変更する指定は追加していません。文言・機能・計算・保存・認証処理を含むHTMLと全JavaScriptは変更前と完全一致しています。

## 検証結果

- 320×568・375×812で、変更前後のカード上部・下部の計8状態を撮影しました。横はみ出し、カード内テキストの文字切れ、ボタンの重なり・遮蔽はありませんでした。
- カード内の全要素・選択肢の計算済み書体がNoto Serif JPで一致しました。
- 文字サイズ・太さ・字間・行間・余白・背景・枠線の計算済みスタイルが変更前と一致しました。
- 文字色の変更は選択欄と説明文のみです。赤い金額表示、円グラフ中央、他のコントロールの文字色を維持しています。
- 他4画面の見出し・下部ナビの書体と寸法、お給料画面の表示金額・内訳文言・保存データの一致を確認しました。
- HTML・全JavaScriptが変更前とバイト単位で一致しています。
