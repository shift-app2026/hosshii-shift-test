# お給料画面：明朝体の統一・文字色の最終調整

変更前は `025fc41`、変更後のアプリコードは `6d22d46`。今回のアプリ変更は `bordeaux-rose.css` だけです。HTML・JavaScriptは変更前と完全一致しています。

## 変更内容

- 「前月」「翌月」「無料お試し終了日」「1日〜末日」を年月表示と同じ Noto Serif JP に統一しました。
- 給与内訳の通常文字、勤務先名・締め期間、年間収入の通常文字、説明文などを焦げ茶ローズ `#302027` に揃えました。
- 円グラフ中央の文字は書体・サイズ・色をすべて維持しています。
- ボルドーボタン内の白文字、赤い強調表示（無料お試し終了日、ハート、内訳見出し、年収の残額等）を維持しています。
- 文字サイズ・太さ・字間・行間・余白・背景・ボタン装飾を指定する追加変更はありません。文言・機能・計算・保存・認証処理は変更していません。
