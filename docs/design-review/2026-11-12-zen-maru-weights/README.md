## 600についての確認と、承認済みの代替

Zen Maru Gothicの公式配布は **300・400・500・700・900** で、600はありません。500と700を読み込んだ状態でも、CSSで600を指定すると実際には700（Bold）が選択されます。

このため、ユーザー確認で承認された **500／700の代替比較** を作成しました。600として表示する、字体を加工して擬似的に細くする、といった方法は使用していません。

ブラウザの実描画フォント情報（CDP）でも確認しました。

|CSS指定|実描画された公式フォント|
|---|---|
|500|ZenMaruGothic-Medium|
|600|ZenMaruGothic-Bold（700と同じ）|
|700|ZenMaruGothic-Bold|

[公式のウェイト情報](https://github.com/google/fonts/blob/main/ofl/zenmarugothic/METADATA.pb)／[使用ファイル・SHA-256](font-source.json)／[描画検証結果](results.json)
