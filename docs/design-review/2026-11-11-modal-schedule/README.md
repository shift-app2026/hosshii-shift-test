# シフト登録ポップアップ・予定表の修正とスマートフォン比較

比較元はPR #8の `c6ca41b`、撮影したアプリコードは `c2be24e` です。同じ架空データ・実際の同梱フォントを使い、320×568・375×812で比較しています。

## 変更内容

### シフト登録ポップアップ

- 【ワンタッチ登録】【勤務時間を登録】【日付入りのシフト一覧】をNoto Serif JP、16px、太さ800、行間24px、文字色#302027に統一しました。
- 見出しを左、＋登録／有給／登録などの操作を右に置く既存の配置を維持しています。日付帯、閉じるボタン、内部スクロールも維持しました。
- 認証状態の処理が挿入する非表示要素の有無によって、先頭に12pxの余白が生じていた差を共通CSSで解消しました。認証処理は変更していません。
- 320pxで既存の時刻入力「00:00」の末尾が見切れていたため、左余白を6pxから2pxに調整しました。文字サイズ・値・時計ボタンの配置は維持し、00:00／09:00／18:00／23:59の全桁が収まることを確認しました。

### 予定表

- 上部の勤務先名一覧を表示せず、既存の「前月のシフトを曜日に合わせて一括コピー」と実行ボタンを配置しました。シフト登録画面のコピー欄も維持しています。
- 日付・曜日の書体、サイズ、太さ、土日祝の色は変更していません。
- 勤務時間は380px以下で17→16px、それより広い画面で18→17px。太さを800→600へ調整しました。
- 時間の右に、時間より2px小さい勤務先名を表示しました。勤務先名の前の色付きマークは予定表内だけ外しました。320pxで長い名前は右側の欄で折り返し、全文を表示します。
- 有給の区別は名前の後ろの「（有給）」で維持しています。時刻なしの有給も、勤務時間数・勤務先名を表示します。
- お給料日は「♡ローズカフェお給料日」のように、実際に登録された勤務先名を使用します。勤務先名はHTMLとして実行されないようエスケープしています。
- コピーの対象月は、その操作をした画面の表示月です。既存の曜日合わせ・入力済み保護・有給除外・保存処理は維持しています。
