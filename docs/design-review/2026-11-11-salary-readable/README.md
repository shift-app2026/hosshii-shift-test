# お給料画面：内訳表の文字サイズ・太さの追加調整

変更前は `55860ed`、変更後のアプリコードは `b81e22d`。お給料画面だけを調整しています。

## 変更内容

- 「来月入金予定」「今月入金予定」は14px・太さ700。320pxでも読みやすいよう「来月／入金予定」「今月／入金予定」の2行で表示します。文言は変更していません。
- 内訳表の項目名・金額は320pxで13px、375pxで14px、太さ600。明朝体を維持し、文字色は柔らかな焦げ茶ローズ（#42282f）にしています。
- カード見出しは16〜17px、勤務先見出しは17〜18pxの明朝体。説明文は14pxの読みやすいゴシック体とし、行間を調整しました。
- 円グラフ中央のフォント・サイズ・太さ・字間・行間、光沢ボタン、入力欄、他の画面は変更していません。
- HTMLの変更は表見出しを2行にする表示用spanだけです。計算・保存・認証処理・確定文言は変更していません。
