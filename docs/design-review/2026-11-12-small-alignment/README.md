# PR #8：実機確認中の追加調整

比較元：`b2b141c`。フォントの種類・配色・給与計算・保存処理はこの段階では維持しています。

- 円グラフ下の説明文は、文言・3行・サイズ・太さを維持して各行を中央揃え。
- 給与内訳の「合計」だけを2文字分右へ。金額列の位置・値は維持。
- カレンダーの日付は17→18px。土日祝色・選択日・♡の形と前後関係は維持。
- 「選択」は1行目の「カ」と同じX座標から開始。320幅でも文字を縮小せず、字間を調整して登録ボタンとの重なりを防止。
- 実行ボタンは両画面とも8px左へ。形・大きさ・縦中央・金／白文字は維持。
- 日付付きシフト一覧見出しは【勤務時間を登録】と同じZen Maru Gothic・18px・700・行間に統一。
- 【バイト先選択】は17px・700。最上部の「シフト登録画面」は320幅18px／375幅19px・700。
- 設定の「お給料の設定」と各見出しは18px。入力値は18px、説明は16px中心へ。太さ500が残っていた選択中勤務先の接尾文・登録上限説明・締め日／給料日ラベル・手当名ラベルは700に修正。勤務先名は18pxのまま全文が収まるよう余白を調整。
- 時給と曜日加算は「時給 1,200 円　土日祝 ＋ 100 円」の1行を両幅で確認。数値は18px、短いラベルは15px・700を維持。入力欄は値の桁数に応じて伸び、大きい金額同士など必要な場合だけグループ単位で折り返し、数字を切りません。
- 有給・交通費・その他の説明と入力値の幅、登録説明の「す。」の孤立も確認。
