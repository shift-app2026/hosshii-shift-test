## 撮影条件

- Chromium / Playwright、幅375×高さ812 CSS px、および幅320×高さ568 CSS px。DPR 2なのでPNGは750×1624px / 640×1136pxです。
- **Google Fontsを実際に取得**し、Noto Serif JP / Noto Sans JP / Cinzelの読み込み完了を待って撮影しました。CSSとフォント計58リソースの取得失敗は0件です。前回のフォールバック書体を含む画像とは条件が異なります。
- 接続環境のHTTPSプロキシ経由でフォントを取得し、同じレスポンスをブラウザへ渡しています。フォントCSSの省略・代替フォントへの置換はしていません。
- LINE / Supabaseはモック、給与・勤務先・シフトは専用ブラウザのテストデータです。実アカウントや本番データを使用していません。
- 表示日は再現性のため **2026年11月11日12:00（Asia/Tokyo）** に固定。円グラフはビー玉アニメーションの終了を待ちました。
- 端末表示領域をそのまま撮影しています。全内容を1枚に伸ばした画像ではありません。必要な箇所にはスクロール後の別画像があります。

## 確認結果と表示上の問題

### 確認できた点

光沢のあるボルドーの時給登録・ワンタッチ登録・設定保存ボタン、明朝体の金額と見出し、実用UIのゴシック体、下部5アイコン、円グラフと真珠調ビー玉、時計の時・分、シフト登録ポップアップを両サイズで撮影しています。

40枚の撮影でページとappScrollの横方向のはみ出しは検出されず、JavaScript例外・フォント取得失敗も0件でした。設定保存ボタンと5列ナビに重なりは検出されませんでした。ナビは320pxで「シフト登録」が2行になる場合がありますが、タイル内に収まっています。

### 報告事項（修正していません）

| 箇所 | 375×812 | 320×568 | 操作への影響 |
| --- | --- | --- | --- |
| 時給入力の確認 | カード上端が約18px画面外 | カード上端が約187px画面外、カード高約943px | 320pxでは上部の×と下部の「閉じる」の両方が画面外となり、Playwrightのクリック到達確認も失敗。375pxでは閉じる操作への到達は可能でした |
| 給料内訳 | 今回の条件では閉じるボタンへの遮蔽なし | 固定年月見出しがポップアップ上部に重なり、×が隠れる | 320pxでも下部の「閉じる」は表示されています。上部×の中心には背景の固定見出しが重なります |
| カレンダー内の操作と下部ナビ | 下部にかかったシフトの「削除」がナビに隠れる位置あり | 初期位置の「＋シフトを登録」がナビに隠れる。スクロール後も下端の削除ボタンが隠れる位置あり | 登録ボタンはスクロール後にクリック到達確認が成功。画面下端の一部操作にはスクロールが必要で、常時操作不能とは区別しています |

目視では、320pxの[ワンタッチ時間登録](320/preset-register-modal.png)で「08:00」「16:00」の末尾が入力欄内で切れていることも確認しました。375pxでは全桁表示されています。また320pxの[設定・時給登録付近](320/settings-register-button.png)では、有給欄の「1時間あたり」の末尾が金額入力欄に隠れます。ページ全体の横はみ出しがない場合でも、入力欄やラベル内部の文字切れは残っています。これらも今回は変更していません。

上記は矩形の重なり判定・ボタン中心のヒットテストと画像の目視を併用して確認しました。スクロール領域にあって未表示の要素や、金額表示として意図的にdisabledになっているボタンは、操作不能なボタンとして扱っていません。部分表示の下端ボタンではヒットテスト結果も併せて確認してください。

今回は再撮影と検証だけの依頼のため、表示問題の修正は行っていません。
