# PR #8：締め日の表示だけを修正

比較基準 `3437a18` → 修正実装 `ae38efb`。320×568 / 375×812、Chromium、DPR 2。架空データのみ使用。比較画像は左が変更前、右が変更後です。

## 修正

- 月末締めの勤務期間は「1日〜末日」から、既存の計算が返す対象勤務期間の終了日を使う「1日〜30日」「1日〜31日」等に変更。通常年2月の28日、うるう年2月の29日にも自動対応します。日付の計算を新しく実装する変更ではありません。
- 設定の締め日だけ、選択肢の表示ラベルを「末日（毎月の最終日）」に変更。**optionのvalueと保存値は従来の `月末` のまま**です。
- 給料日の選択肢は従来どおり「月末」。20日等の通常締め日、未設定の表示も変更しません。
- 長い締め日ラベルを小さく戻さずに表示するため、締め日／給料日の設定行をそれぞれ全幅にしました。フォントは16pxを維持。色・ボタン・他のデザインは維持しています。

## 検証

[自動テスト](../../../tests/month-end-display.cjs) / [結果](results.json)

- 2026年1〜12月、2024年2月、2028年2月、2000年2月、2100年2月、2027年1月の17か月を両幅で確認。28・29・30・31日の表示に合格。
- 月末以外の20日締め「21日〜翌月20日」は修正前と同じ。
- 保存値 `月末` と既存の数値 `31` の月末扱い、10日払い／月末払いの組み合わせで、表示が既存計算の終了日と一致することを確認。
- 締め日・給与計算・保存関連の6関数のソース文字列が修正前と完全一致。17か月分の給与額と勤務期間の計算結果も一致。
- 締め日の全optionのvalueが修正前と一致。給料日側のvalueとラベルも全件一致。
- 選択→保存したJSONが修正前後で一致し、`closeDay: "月末"` を保持。再読み込み後の選択も維持。
- 表示を描画しただけでは保存データを書き換えないことを確認。
- 20枚を撮影し10枚の比較画像を作成。勤務期間は1行で収まり、横方向のはみ出し・下部ナビとの重なりなし。
- 設定の長い選択ラベルは16pxのまま、文字幅約160pxに対し表示可能幅176px（320px時）／228px（375px時）を確保し、全文表示を確認。
