## 検出した既存問題

保存領域が空の初回起動で、`getSettingsFormHtml` 内の `j.name` 参照時に例外が発生します。元HTMLと変更後HTMLの両方で、以下の同一スタックを再現しました。

```text
TypeError: Cannot read properties of undefined (reading 'name')
    at getSettingsFormHtml (:3072:14)
    at renderSettingsJobContent (:3064:29)
    at window.onload (:2010:7)
```

デザイン移植による新規不具合ではありません。今回のPRでは機能JavaScriptの変更を避け、そのまま記録しています。テストでも元HTMLとの再現一致を確認します。初回利用の確認時には別途対処が必要です。

## 再実行

Node.jsとPlaywright（Chromium導入済み）が必要です。リポジトリルートでHTTPサーバーを起動し、別ターミナルで実行します。

```sh
python -m http.server 8765 --bind 127.0.0.1
node tests/design-review.cjs
```

`CHROMIUM_PATH`でブラウザのパス、`REVIEW_URL`でローカル検証URL、`REVIEW_ARTIFACTS`で画像の保存先を変更できます。既定の画像保存先はOS一時ディレクトリ内の `hosshii-design-review` です。テストは専用ブラウザコンテキストでテストデータを使用し、LINE/Supabase通信を置き換えます。基準コミット `46908d4` を参照できるGit履歴が必要です。
