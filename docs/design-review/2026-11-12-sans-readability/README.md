## 今回の調整

- 円グラフ中央を除き、5画面・ポップアップ・勤務先選択・時間選択・登録済みデータ・入力欄・単位・記号・下部タブを **Noto Sans JP** に統一。通常は700、見出し・強調・ボタン等は800を基本としました。
- 文字サイズは今回小さくしていません。現在の14〜17pxの本文・入力や、下部タブ13px等を維持。薄い通常の灰色説明を濃い焦げ茶ローズ #21151a に寄せました。
- 下部5タブの文字もNoto Sans JP・800に統一。SVGアイコンの線を2.3にして輪郭を明瞭化。形・サイズ・選択色は維持。
- ワインレッド／シャンパンゴールド、光沢ボタン、勤務先識別色、土日祝色、赤い金額は維持。登録・保存の金色→白→再編集で金色という仕様も維持。
- 年収の壁の受取済み給与は **「実際の年・月までに受け取ったお給料」／「実際の金額（右寄せ）」** の2行に変更。年月・金額の計算は変更していません。320pxでも見出しが1行に収まるよう、この部分の横余白を調整しました。
- 320pxの年収目安の選択欄と残額は、ラベルと値を上下に分け、「確認する金額」「130万円までの残り」等の語尾だけが折り返される状態を解消。375pxでは従来の横並びを維持。
- ワンタッチ時間登録の注意書きは必要に応じて折り返し、320pxで登録ボタンが画面外へ押し出される状態を解消。文言・登録操作は同じです。

円グラフ全体とその中央は、各要素の書体・サイズ・太さ・色・行間・背景・枠・余白が修正前と一致することを確認しました。
