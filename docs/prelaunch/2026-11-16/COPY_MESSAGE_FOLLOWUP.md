# 『一括コピー』案内の修正・再テスト（2026-11-16）

対象: PR #10 / fix/trial-prelaunch-20261116。前回確認した「別画面で編集中なのに無料お試し終了と表示」を修正しました。

案内の選択を共通化し、シフト登録・予定表のコピーと常設の編集制限案内で同じ理由を使います。

| 理由 | 表示 |
|---|---|
| 別画面で編集中 | 別画面を閉じて「再確認」、閲覧は可能 |
| 保存競合 | 入力を保持していること、必要な入力を控えてから再確認 |
| 利用状況確認中 | 確認が終わるまで登録・変更不可 |
| 利用状況の確認失敗 | 通信確認と再確認、閲覧は可能 |
| 期限切れ | 無料お試し終了、登録・修正・削除不可 |
| 理由不明 | 利用状況と保存状態の再確認を促す。期限切れと断定しない |

状態が変わったときはコピー直下の案内も更新。編集可能に戻った場合、古い禁止案内を非表示にします。給与計算・保存形式・コピーの検査や書込処理は変更していません。
