## 確認できた定義

- 2表21列。app_users.idはbigint GENERATED BY DEFAULT AS IDENTITY、app_backups.idはbigint GENERATED ALWAYS AS IDENTITY。UUIDへ変更しない。
- 6制約、8有効インデックス。application_codeにはUNIQUE制約としてではなく一意インデックスがある。square_customer_idにも一意インデックスあり。
- line_user_idにはapp_usersで重複する一意インデックスがあるが、再現のため削減しない。
- 2トリガー通常有効。3関数すべてSECURITY INVOKER。generate_application_code/set_trial_end_dateは空search_path指定。prevent_trial_start_changeには指定なし。元の定義を維持。
- RLSは両表ENABLE、FORCEなし、ポリシー0件。公開用ポリシーは追加しない。
- 3関数にパスワード/秘密キー/トークン/外部送信先の直書きは見当たらない。アプリ番号はextensions.gen_random_bytes(12)をhex化する方式で、固定秘密値ではない。
