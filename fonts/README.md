# Zen Maru Gothic

Official faces: Medium (500) and Bold (700), copyright 2021 The Zen Maru Gothic Project Authors. Licensed under SIL Open Font License 1.1; see zenmarugothic-OFL.txt.

Source: https://github.com/google/fonts/tree/main/ofl/zenmarugothic

The official ZenMaruGothic-Medium.ttf and ZenMaruGothic-Bold.ttf were losslessly encoded as WOFF2 with fontTools. Weight classes, character maps and horizontal glyph metrics were checked after encoding. No new weight or synthetic 600 was created. Original source file hashes are recorded in docs/design-review/2026-11-12-zen-maru-weights/font-source.json.

These two faces are served from the app's own origin through zen-maru.css. The existing Noto fonts remain available for the unchanged jewel-ring typography.
