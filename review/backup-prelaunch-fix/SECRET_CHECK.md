# SUPABASE_SECRET_KEYS.default の設定確認方法（今回は未実施）

秘密値の取得・表示・ログ出力は行っていません。手順だけです。

1. 対象のSupabaseプロジェクトが正しいことを確認。
2. Edge FunctionsのSecrets/環境変数管理画面で、名前SUPABASE_SECRET_KEYSの登録情報を確認。値の表示・コピー・スクリーンショット共有は不要。
3. 一覧の名前確認だけでは、JSON内のdefaultが有効な空でない文字列かまでは確定できません。プラットフォーム注入の変数は一覧表示だけで判定できない場合もあります。
4. すでにランタイムの構成診断があれば「設定OK/不足」の結果だけ確認。なければ、承認後の診断で内部的にJSON解析・defaultの型/空文字を判定し、真偽値だけ返す方式にする。内部読取りすら行わずにdefaultの有効性を厳密に確認することはできません。
5. 診断のための本番関数追加・変更・デプロイは今回行わない。キーの先頭/末尾、長さ、JSON全体、ハッシュも報告不要。ここへの秘密値の貼り付けは不要。

この候補コードは既存と同じdefaultを使用。未設定/不正なら500で止まり、バックアップDB操作は行いません。service_roleへの自動フォールバックやキー再発行は追加していません。
